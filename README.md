# 🎮 チーム制作発表：Aチーム「 Treasure Chest」

## 🧩 1. プロジェクト概要
DOTWeenの習得を目標にして、Tweenアニメーションに力を入れました。


- **開発期間**：2025/10/2 〜 2025/10/16（全14日）
- **使用ツール**：Unity 20XX.X.X / Git / GitHub 
- **開発人数**：3人チーム（伊丹/ 林 / 松下）

---

## 🎯 2. ゲーム概要　💎
- **タイトル**：  TreasureChest
- **ジャンル**：スリーシェルゲーム
- **プレイ時間目安**：10分程度  

Unityちゃんがアタリが1つハズレが2つの合計3つの宝箱からアタリを選択するゲームです。
コインのある宝箱を選び続けてハイスコアをめざしましょう！

### 🌟 コンセプト　
単純な動体視力や、集中力を競うゲームです。

---

## 🕹️ 3. 遊び方（操作説明）
| 操作 | 内容 |
|------|------|
| ↓ / ↑ | 移動 |
| ← / → | 回転 |
| ｘ | Chestを選択 |




---

## 🧠 4. こだわりポイント・技術的特徴
- DOTweenで滑らかなUIアニメーションをChestとUntiyちゃんで同期
- GameManager側からはUntiyちゃんの状態とGameのStepの状態を管理してステートメントパターンで管理
- ランキングにはシングルトンクラスのフィールドにはListとして保持、sceneが変っても
DontDestroyOnLoad(gameObject)を使いgameObjectをシーン遷移時にランキングデータが消えないようにしている
